# 🚗 Ferrari Website

A modern and responsive Ferrari-themed website built using HTML and CSS.

## 📖 About the Project

This project showcases Ferrari's rich history, iconic models, and outstanding performance through a visually appealing and responsive website design.

## ✨ Features

- Responsive design
- Ferrari-themed user interface
- History section
- Models section
- Performance statistics
- Hover effects and transitions
- Clean and modern layout

## 🛠️ Technologies Used

- HTML5
- CSS3



## 🚀 How to Run

1. Download or clone the repository.
2. Explore the Ferrari website.
